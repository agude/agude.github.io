# Markdown Output for Authors

The Markdown alternate uses the Markdown branches of these includes:

- `figure.html` emits a Markdown image and, when provided, its caption. Write
  captions as Markdown; inline formatting is supported.
- `video.html` emits a `[Video](file)` link.
- `chatgpt_edit.html` emits `Prompt` and `Output` labels with the supplied text
  quoted as block content. Paragraphs, lists, and fenced code in the text keep
  their Markdown structure.
